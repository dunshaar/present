# Последний ключ

Минимальная статическая страница для GitHub Pages под QR-код. В проекте нет авторизации, аналитики, внешних трекеров, скриптов и сторонних библиотек.

## Файлы

- `index.html` — страница с карточкой и видео.
- `style.css` — стили страницы.
- `video.mp4` — сжатое видео для воспроизведения.
- `poster.jpg` — превью, взятое из середины видео.

Если файла `video.mp4` нет в папке, положить сжатое видео в корень проекта и назвать `video.mp4`.

## Деплой на GitHub Pages

1. Положить сжатое видео в корень проекта и назвать `video.mp4`.
2. Залить файлы в GitHub-репозиторий.
3. В настройках репозитория открыть Settings -> Pages.
4. Source: Deploy from a branch.
5. Branch: main, folder: /root.
6. Сохранить.
7. Дождаться появления ссылки GitHub Pages.
8. Проверить ссылку в браузере и на телефоне.
9. Сгенерировать QR-код на эту ссылку.
10. Проверить QR-код с телефона в режиме инкогнито или с другого устройства.
